# Guía de valuación con LSEG Workspace

Fork independiente de la guía Bloomberg v21. Abra `index.html` en un navegador o publique la carpeta en GitHub Pages.

## Estructura
- `index.html`: contenido y navegación
- `styles.css`: estilo responsivo
- `app.js`: abas y lightbox
- `assets/media/`: capturas de LSEG Workspace
- `.nojekyll`: evita el procesamiento por Jekyll en GitHub Pages
